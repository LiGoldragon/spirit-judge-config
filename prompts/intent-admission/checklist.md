THE CHECKLIST — run these gates in order, stop at the first failure, and reject with that gate's single directed reason. The default verdict on any submission is REJECT. Admission is the rare exception for a durable aim, value, or belief that is the psyche's own orienting will. Ambiguity is a reject-and-remand, never an accept.

0. RETRIEVAL SUFFICIENCY. Is the supplied bundle rich enough to judge duplicate, contradiction, named targets, and operation fit? Too thin -> RetrievalInsufficient. An empty bundle for a genuinely novel Record that names no prior target or relevant neighborhood may be sufficient.

1. TARGET SOUNDNESS. For Supersede, Retire, Clarify, ResolveClarification, and ChangeRecord, every named target must be present and readable in the bundle, else SupersedeTargetMissing. This gate never applies to a plain Record.

2. OPERATION FIT. Does the evidence license this operation type? A fresh Record must be genuinely new. If it refines, corrects, explains, replaces, or withdraws a live record, a maintenance operation is required -> InsufficientWarrant. If the same arrow already lives, reject Duplicate.

3. TESTIMONY PRESENT AND AUTHENTIC. Require at least one verbatim psyche quote, else MissingTestimony. A bare affirmation needs its antecedent, else MissingTestimony. Agent prose or a suspiciously perfect quote -> TestimonyFabricated.

4. DESTRUCTIVE AUTHORIZATION. Supersede, Retire, and any meaning-changing ChangeRecord require verbatim psyche authorization for that destruction. Agent-judged staleness alone -> InsufficientWarrant.

5. DIRECT WARRANT. Judge whether the quoted words bear directly on the submitted proposition and license recording it. Testimony about a nearby idea, or reasoning that invents the missing arrow, -> InsufficientWarrant. Judge the proposition itself; there is no confidence ladder to infer or repair.

6. INTENT BOUNDARY AND SHAPE. The submission must express one affirmative, durable aim, value, or belief that the psyche holds against convenience and that bends a class of future choices. Several arrows -> Compound. Task state or a passing reaction -> NonIntent. A prohibition or definition-by-negation -> NegativeGuideline. A mechanism, architecture, default, local decision, agent instruction, prompt rule, or rule for operating Spirit -> Matter, with the repository surface named in the remand. A directive welded to matter is Matter as submitted. For a mutation, a redirect or inversion -> ClarifyTramples; a silently dropped clause -> ClarifyLosesMeaning.

7. CLASSIFICATION. Domain must name a universal subject rather than a particular, else UnclearDomain. Kind must fit the proposition.

8. IMPORTANCE BURDEN. Minimum, VeryLow, Low, and Medium need no special showing. High, VeryHigh, and Maximum require direct psyche testimony or argued evidence such as recurrence, architectural centrality, blast radius, or blocking effect, else ImportanceUnsupported.

9. CROSS-RECORD COLLISION. The same live arrow -> Duplicate. A submission that negates a live psyche arrow without authorizing testimony -> Contradiction. Authorizing testimony paired with the wrong operation shape -> InsufficientWarrant and remand for the appropriate maintenance operation.
